# artificialanalysis.ai 활용안 — "memdex는 돈을 아낀다"를 숫자로 증명하기

> memdex의 토큰 절약(자체 bench 측정) × AA의 모델 가격(독립 측정) = 달러 절감.
> 2026-11-04 초안. **게시 전에 AA에서 현재 가격을 다시 뽑아 갱신할 것.**

---

## 1. 왜 이 조합이 강한가

- **우리가 가격을 주장하면 이해관계가 있다.** AA가 측정한 가격을 인용하면 독립 근거가 된다.
- memdex는 "토큰 수"를 측정하고(자체 bench, 결정적), AA는 "토큰당 가격"을 측정한다(독립).
- **곱하기는 양쪽 측정의 조합** — 각각 출처를 명시하면 반박할 구석이 없다.

## 2. 계산식 (README/홍보용 표준 문구)

```
절감액 = (전체 재읽기 토큰 − memdex 개요 토큰) × AA 기준 모델 입력 가격
```

memdex bench 실측 (66파일 사이트 저장소):
- 전체 읽기: **154,105 토큰** → memdex 개요: **3,471 토큰** → 절약 **150,634 토큰/회 (97.7%)**

## 3. 달러 환산 (예시 — 게시 시점에 AA에서 갱신)

| 항목 | 값 | 출처 |
|---|---|---|
| 절약 토큰/회 | 150,634 | memdex bench (자체 측정) |
| Top 코딩 모델 입력가 예시 | $15.00 / M tokens | artificialanalysis.ai (예시값, 갱신 필요) |
| **절약/회** | **$2.26** | 계산 |
| 세션/일 × 에이전트 수 | 10 × 4 = 40회 | 사용 시나리오 (명시) |
| **절약/일** | **$90** | 계산 |
| **절약/월** | **≈ $2,700** | 계산 |

> 주의: "월 $2,700" 같은 큰 숫자는 시나리오 가정(하루 40회 전체 재읽기)에 의존한다.
> 정직한 문구: "**전체 재읽기 1회당 ~$2.26 절약**(AA 가격 기준). 당신의 세션 빈도에 곱하면
> 당신의 절감액." — 가정을 숫자에 숨기지 않기.

  가정은 시나리오로 분리해 표기했습니다."

## 5. AA에서 가격 뽑는 절차 (게시 전 체크리스트)
- [ ] https://artificialanalysis.ai/models → Price ($ per M tokens) 정렬
- [ ] 코딩 에이전트로 실제 쓰이는 모델 2~3개(예: Opus 계열, GPT-6 계열, Gemini 계열) 입력가 기록
- [ ] "2026-11-XX 기준" 날짜 명시
- [ ] README/트윗의 숫자를 예시값 → 실측값으로 교체
- [ ] 가격은 수시로 변하므로 "비율은 memdex, 가격은 AA" 문구 유지

## 6. 하지 말 것
- AA의 벤치마크 점수를 memdex와 연결해 과장하지 않는다 (memdex는 모델이 아니라 캐시 레이어)
- "AA가 memdex를 검증했다"는 식의 표현 — 절대 금지 (우리가 인용만 하는 것)
