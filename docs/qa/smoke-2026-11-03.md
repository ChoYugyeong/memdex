## QA에서 발견해 수정한 것

1. **CLI `brief`가 `MEMDEX_SKILL_HOME`을 무시** — `cmd_brief`가 `render_brief`에 home을 넘기지 않아, 스킬
   홈을 격리한 환경(테스트, 멀티 계정)에서도 실제 홈을 걷고 있었다. MCP 경로(`Session.brief`)는 이미
   정상. `cmd_brief`에서 `home=s.home_dir` 전달로 수정.
2. **시나리오 테스트의 환경 누수** — `MEMDEX_AGENT`를 복원하지 않아 뒤 모듈(test_skills)의 세션 정체성을
   바꿨다. setUp/tearDown에서 저장·복원으로 수정 (제품 버그 아님).
3. (환경 제약 기록) 이 머신 하네스는 자식 프로세스의 **파이프 캡처를 허용하지 않음** — pre-edit 시나리오는
   stdout/stderr을 임시 파일로 리다이렉트하는 방식으로 작성 (CI에서는 파이프도 정상).
